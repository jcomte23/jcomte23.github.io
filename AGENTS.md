# AGENTS

Este repositorio contiene un sitio web de portafolio personal para Javier Cómbita Téllez. El propósito de este archivo es ofrecer una guía rápida sobre los agentes o asistentes que pueden trabajar con este proyecto.

## Proyecto
- Nombre: `jcomte23.github.io`
- Tipo: Portafolio personal / sitio web estático
- Tecnologías principales: `Vite`, `HTML`, `CSS`, `SCSS`, `JavaScript`, `Bootstrap`
- Estructura relevante:
  - `index.html` — página principal y entrada del sitio
  - `src/js/main.js` — lógica de interacción del menú y mejoras de scroll/lazy loading
  - `src/scss/style.scss` — estilos principales del sitio
  - `public/` — recursos estáticos como imágenes y favicon
  - `package.json` — dependencias de desarrollo y scripts del proyecto

## Scripts disponibles
- `npm install` — instalar dependencias
- `npm run dev` — iniciar servidor de desarrollo de Vite
- `npm run build` — generar versión de producción
- `npm run preview` — vista previa del build local

## Uso recomendado de agentes
- Actualizar contenido de portafolio, secciones y meta tags.
- Revisar y mejorar accesibilidad, SEO y rendimiento.
- Ajustar estilos y diseño responsivo.
- Editar datos de proyectos, enlaces y descripciones.
- No crear cambios arbitrarios fuera de la estructura existente sin verificar la intención.

## Convenciones del repositorio
- El proyecto está orientado a un público hispanohablante, con títulos y secciones en español.
- Mantener la consistencia en marcas de tiempo, enlaces y atributos de accesibilidad.
- Usar las rutas locales `public/` y `src/` que ya están en uso.
- El sitio está pensado para ser una demostración profesional, por lo que las correcciones deben priorizar limpieza, claridad y presentación profesional.
