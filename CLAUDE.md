# CLAUDE

## Contexto del proyecto
Este repositorio es un sitio web de portafolio personal para Javier Cómbita Téllez. El sitio está construido con Vite y utiliza HTML, SCSS, JavaScript y Bootstrap. El contenido principal está en `index.html`, la lógica de interacción está en `src/js/main.js` y los estilos están en `src/scss/style.scss`.

## Uso práctico
- Para ejecutar localmente: `npm install` y luego `npm run dev`.
- Para construir la versión final: `npm run build`.
- Para revisar una versión de producción localmente: `npm run preview`.
